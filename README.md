## 학생 화면
1. 🔍 탐정 출발 → 반·번호 고르기(이 크롬북에 기억)

3. 무슨 소리? → 귀로 예상(띵동이 얼굴 3개) → 기계로 재기(3·2·1 뒤 5초) → 결과(숫자·색·귀와 기계 비교)
4. 📒 내 탐정 수첩(내 기록·배지 6종) · 🗺️ 소리 지도 · 💌 띵동이 편지 · ⭐ 발소리 지킴이 도장판

## 측정 방식(기존 앱과 동일)
2048 샘플 RMS → dBFS+100 → 0~100점, 5초 동안 0.1초마다 → 점수 = (평균+최대)/2. 초록 < 50 ≤ 노랑 < 65 ≤ 빨강(설정 시트에서 변경).
인터넷이 끊기면 기록을 크롬북에 보관했다가 자동으로 다시 보냅니다.
