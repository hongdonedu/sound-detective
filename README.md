# 🔔 소리 탐정단 띵동이

초등 1학년 창의적 체험활동(디지털) · 소리·소음 환경교육 웹앱 — 부산 명진초 최일훈 · 바이브코딩(2026)

귀로 느끼고(예상) → 기계로 재고(크롬북·스마트패드 마이크) → 비교해요. 녹음은 만들지도 저장하지도 않고, **소리 점수(숫자)만** 구글 시트 `소리탐정단_1학년_연구데이터`에 저장합니다.

## 바로가기
- 학생 앱: https://hongdonedu.github.io/sound-detective/
- 선생님: 첫 화면 🔑 선생님 → 교사 코드(설정 시트의 값)

## 학생 화면
1. 🔍 탐정 출발 → 반·번호 고르기(이 기기에 기억)
2. 오늘의 미션(교사가 고른 차시) → 🎤 소리 재러 가기
3. 무슨 소리? → 귀로 예상(띵동이 얼굴 3개) → 기계로 재기(3·2·1 뒤 5초) → 결과(숫자·색·귀와 기계 비교)
4. 📒 내 탐정 수첩(내 기록·배지 6종) · 🗺️ 소리 지도 · 💌 띵동이 편지 · ⭐ 발소리 지킴이 도장판

## 측정 방식(기존 앱과 동일)
2048 샘플 RMS → dBFS+100 → 0~100점, 5초 동안 0.1초마다 → 점수 = (평균+최대)/2. 초록 < 50 ≤ 노랑 < 65 ≤ 빨강(설정 시트에서 변경).
인터넷이 끊기면 기록을 기기에 보관했다가 자동으로 다시 보냅니다.

## 교사 화면
오늘의 차시 · 색 기준 · 반별 측정 현황 · 교실 소리 신호등(화면 보이며 기록 / 기록만) · 띵동이 편지 올리기 · 교실 소리 기록 요약

## 그림
ChatGPT 이미지 생성(키아트·띵동이 표정 4종·탐정 아이 2명·아이콘 12종) → 검정/흰 배경 두 장으로 배경 제거(src-images → assets)

## 스마트패드에서 쓰기
- 갤럭시탭: **크롬** 또는 **삼성 인터넷**으로 열어요. 아이패드: **사파리**(또는 크롬)로 열어요.
- 카카오톡·네이버 앱 안의 창에서는 마이크가 켜지지 않아요. 화면에 안내가 나오면 크롬·사파리로 다시 열어요.
- 처음 '재기 시작!'을 누르면 마이크 허용을 물어봐요 → **허용**.
- 패드 화면이 꺼졌다 켜지면 마이크가 쉬어요. 그때는 단추를 한 번 더 누르면 다시 켜지고, 0점은 기록하지 않아요.
- 기기 종류(Chromebook / iPad / Android패드)는 시트의 기기 칸에 함께 남아요. 기기마다 마이크 감도가 달라서, **한 반은 같은 종류의 기기**로 재는 것이 좋아요.
- 선생님 화면 코드는 화면에 표시되지 않아요(●로 가림). 바꾸려면 시트 '설정' 탭의 '교사코드' 값을 고쳐요.
